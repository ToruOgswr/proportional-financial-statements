# 比例縮尺財務諸表の作成Webサイト

財務諸表の金額をブロックの大きさに置き換え、企業規模、財務構造および利益構造を視覚的に比較するための教育用Webサイトです。利用者が用意した財務データをブラウザ内で処理し、比例縮尺財務諸表を作成します。

公開サイト: <https://toruogswr.github.io/proportional-financial-statements/>

## 主な機能

- 1社の貸借対照表・損益計算書の表示
- 複数社の規模・構成比較
- 同一企業の時系列比較
- 実額表示と構成比表示
- 中粒度・高粒度の切り替え
- 表形式データの一括貼り付け
- SVG・PNG形式での保存
- 貸借不一致、損益不一致、異常値の警告

## 入力項目

一括貼り付けでは、次の見出しを使用します。

```text
企業名,年度,単位,流動資産,固定資産,流動負債,固定負債,現預金,売上債権,棚卸資産,有形固定資産,仕入債務,純資産,売上高,売上原価,販売費及び一般管理費,営業利益
```

単位には「円」「千円」「百万円」を指定できます。空欄の金額は0として扱われます。欠損値と実際のゼロは区別されないため、利用前に原資料を確認してください。


## データの取扱い

- 入力された財務データは利用者のブラウザ内で処理され、本アプリケーションから外部サーバーへ送信されません。
- 入力内容をデータベース、Cookieまたはブラウザの永続的な保存領域に保存しません。
- 個人情報、学生情報、未公開情報、営業秘密その他の機密情報を入力しないでください。
